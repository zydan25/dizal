# Dizal Phase 5 — الصرف والتحصيل وكشف حساب المزارع

## ما تم تنفيذه
- صرف ديزل بالدبة.
- تحويل الدبة إلى لتر.
- سعر بيع اللتر.
- بيع نقدي وآجل ومختلط.
- حساب الدين.
- منع الصرف فوق السقف أو حد المديونية.
- منع الصرف لمزارع غير معتمد.
- منع الصرف فوق مخزون الخزان.
- سند صرف DSP.
- تحصيل وسداد.
- سند قبض RCV.
- توزيع السداد على أقدم الديون.
- كشف حساب المزارع.
- تسجيل تكلفة الديزل المستهلك.
- الربح الإجمالي لكل عملية.
- FIFO Stock Layers لتكلفة المخزون.

## دورة الصرف
المزارع -> الخزان -> الدباب -> السعر -> المدفوع -> الحساب -> التحقق من السقف والمخزون -> استهلاك FIFO -> خصم المخزون -> قبض النقد -> السند.

## الدين
كل عملية صرف تحمل الإجمالي والمدفوع والدين بالدباب.
عند السداد ينشئ النظام FarmerPaymentAllocation ويربط السداد بالصرفيات الأقدم.

## تكلفة الديزل
كل توريد معتمد ينشئ طبقة مخزون تحتوي الكمية والتكلفة.
عند الصرف يتم استهلاك الطبقات الأقدم أولًا، ويُسجل FuelStockConsumption.

## القيود
- لا صرف لمزارع غير معتمد.
- لا تجاوز للسقف.
- لا تجاوز لحد الدين.
- لا مخزون سلبي.
- لا سحب من صندوق غير كافٍ.
- الموظف لا يغير السعر دون fuel.price.override.
