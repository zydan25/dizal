# Dizal Phase 4 — المزارعون والاعتماد والمرفقات

## ما تم تنفيذه

- Farmer.
- FarmerDocument.
- FarmerQuotaMovement.
- تعيين المزارع لموظف.
- سقف المزارع.
- حد المديونية بالدبة.
- حد عدد المزارعين للموظف.
- رفع البطاقة الأمامية والخلفية.
- رفع العقد/الالتزام.
- ملفات إضافية.
- حالة submitted.
- اعتماد المدير.
- طلب استكمال.
- رفض.
- تعديل السقف مع تاريخ السبب.
- واجهة الهاتف للموظف والمدير.

## دورة المزارع

الموظف:
إضافة -> رفع المرفقات -> submitted.

المدير:
مراجعة -> approved أو changes_requested أو rejected.

بعد approved يستطيع المزارع الدخول في دورة الصرف عند اكتمال مرحلة الصرف.

## الحدود

حد عدد المزارعين:
من ProjectSettings أو EmployeeProfile override.

حد المديونية:
من ProjectSettings أو EmployeeProfile override.

الموظف لا يستطيع تجاوز الحدود.

المدير يستطيع تعديل السقف عبر صلاحية farmers.quota.change.

## المرفقات

تحفظ الملفات مع:
- UUID للتخزين.
- النوع.
- الحجم.
- SHA-256.
- اسم العرض.
