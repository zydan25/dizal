### المخزون

الدبة:
وحدة إدخال/عرض مشتقة من ProjectSettings.drum_liters.

### تكلفة اللتر
في Phase 3 تستخدم تكلفة الاقتناء المباشرة:
قيمة الديزل + التوصيل + الرسوم الأخرى.

إذن:
landed cost = diesel + delivery + other fees

unit cost = landed cost / liters

مثال:
1,150,000 + 5,000 = 1,155,000
1,155,000 / 2,000 = 577.5

هذه سياسة قابلة للمراجعة لاحقًا إذا قرر المشروع أن بعض الرسوم مصروف تشغيلي بدلًا من تكلفة مخزون.

## قواعد الأمان
- لا مخزون سلبي.

- لا اعتماد مرتين.
- لا تعديل مباشر لحركة المخزون.
