# Dizal Phase 7 — التقارير والسندات

## ما تم تنفيذه
- لوحة تقارير المشروع.
- تقرير ديون المزارعين.
- تقرير أداء الموظفين.
- تقرير المخزون والالتزام.
- Document View.
- Print View بنمط A4.
- اسم المشروع ورقم السند والترويسة والتذييل ومكان توقيع المدير.

## فلسفة التقارير
على الهاتف: ملخصات وبطاقات.
على سطح المكتب: يمكن توسيعها لاحقًا إلى جداول كاملة.

## السندات
كل عملية مالية أو تشغيلية تنشئ Document مرتبطًا بمصدر العملية، ورقمه يولد من ProjectSequence.

## الطباعة
تم إنشاء Print CSS متوافق مع A4. يمكن لاحقًا إضافة PDF server-side إذا كان WeasyPrint متاحًا في بيئة الخادم.
