# Dizal Phase 6 — المحاسبة والتسويات والربحية

## ما تم تنفيذه
- دليل حسابات داخلي.
- JournalEntry / JournalLine.
- التحقق من توازن القيود.
- ربط القيود بالمستند والمستخدم.
- مصروفات تشغيلية.
- سند EXP.
- تسوية الموظف.
- المتوقع والفعلي.
- العجز والزيادة.
- الراتب/العمولة.
- التحويل للمدير.
- رأس المال التشغيلي المتبقي.
- حساب مبيعات الموظف.
- تكلفة المبيعات.
- مجمل الربح.

## أمثلة القيود
إضافة رأس المال:
مدين 1100 / دائن 3000.

تسليم الموظف:
مدين 1110 / دائن 1100.

شراء ديزل:
مدين 1200 / دائن 1110.

بيع نقدي:
مدين 1110 / دائن 4000
ومدين 5000 / دائن 1200.

بيع آجل:
مدين 1400 / دائن 4000
ومدين 5000 / دائن 1200.

السداد:
مدين 1110 / دائن 1400.

هذه طبقة محاسبية خلفية ولا تظهر للمستخدم التشغيلي إلا في تقارير المدير.

## التسوية
تعطي المدير:
- المبلغ المتوقع في صندوق الموظف.
- المبلغ الفعلي.
- العجز.
- الزيادة.
- المبيعات.
- تكلفة المبيعات.
- مجمل الربح.
- المصروفات.
- راتب الموظف.
- المبلغ الذي يمكن تحويله.
- رأس المال التشغيلي الذي يجب الاحتفاظ به.

## ملاحظة
تصنيف بعض الرسوم والرواتب وسياسة رأس المال تحتاج اعتماد المحاسب عند جعل التقارير محاسبية رسمية، لكن النظام الآن يملك طبقة بيانات وقيود قابلة للتدقيق.
